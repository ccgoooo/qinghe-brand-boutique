# qh-robots-s3

A multi-page website for Qinghe Atelier with home, about, products, and contact pages.

The site presents the fictional brand and its products. Its contact page includes a form for a name, email, and message, with a success message after submission. It is built with TanStack Start and TypeScript.

This project was built with [Lovable](https://lovable.dev).
